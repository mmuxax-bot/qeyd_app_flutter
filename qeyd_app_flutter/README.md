# Qeyd App

Flutter üçün hazırlanmış giriş (splash) və ilkin ana səhifə.

## İşə salmaq

1. Flutter SDK quraşdırın.
2. Layihə qovluğunda platforma fayllarını yaradın:
   `flutter create .`
3. Paketləri götürün:
   `flutter pub get`
4. İşə salın:
   `flutter run`
5. APK yaradın:
   `flutter build apk --release`

Hazır APK yolu: `build/app/outputs/flutter-apk/app-release.apk`
